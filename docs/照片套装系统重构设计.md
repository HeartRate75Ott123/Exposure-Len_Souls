# 照片套装系统重构设计（固定版）

> 本文档锁定照片套装系统的重构方案，所有实现以此为准。长对话易丢失，凡与本文冲突以本文为准。
> 适用范围：NeoForge 1.21.1 模组 `lensouls`，根 `lensouls-template-1.21.1`。

---

## 1. 目标与设计原则

1. **只做小集**：每个套装 = 3~5 个精确生物（如 僵尸+小鸡+僵尸马），预计 **50 套**。命名为**意境史诗风**（如「枯骨行军」「熔心誓约」）。
2. **删光宽泛大集**：删除所有按大类别/大模组划分、且只给数值的宽泛套装。
   - 待删：`undead, dragon, aquatic, ender, arthropod, cataclysm, legendary, twilight, blockfactory, flying, undead_knight, venom, frost, abyss, spellcaster, radiation`。
3. **保留**：
   - `boss_barrage`（首领套）：自动检测 Boss 血条（`isBoss()`），伤害目标为最大生命 ≥ 200 的生物。
   - 代码层四元素抑制 `PhotoSetEffects.applyGenericSuppress`：实时读 `attacker_element` 活性配置，非 defs 集。
4. **效果精细有趣**：以数值为基础，但优先用上新机制——条件触发 / 弹幕 / 活性提升 / 转化链，避免纯数值堆砌。
5. **描述双清楚**：每条必须写清「集齐 N 张<真实译名>照片」+ 具体效果；tooltip 中每个效果独立成行、按类配色。

---

## 2. 实体来源

- 可拍摄生物 = `PhotographEffectRegistry` 登记的全部实体（mc + cataclysm / twilight / eternal_starlight / legendary_monsters / alexscaves 等）。
- 套装成员来自 `membership.json`（实体 id → setId 标签列表）。一个生物可入多个小集（多归属，让 50 套互相交织）。
- 首领套不依赖 membership 标签，由照片的 `lensouls:is_boss` 标记驱动。

---

## 3. 效果词表（代码 token → 中文显示 → 配色）

配色：§c 进攻/伤害，§a 防御/生存，§9 增益/机动，§e 条件前缀，§5 转化 / 四元素抑制。

### 进攻 / 伤害（§c）
| 代码 token（示例） | 中文显示 |
|---|---|
| `dmg_mod:<set>:1.2` | 你对套装所需的这几种生物造成伤害 +20% |
| `barrage_dmg:1.15` | 弹幕伤害 +15% |
| `on_hit_effect:poison:0.3:100:1` | 造成伤害时 30% 概率附加中毒2效果 |
| `on_hit_effect:weak:0.1:60:0` | 造成伤害时 10% 概率附加虚弱1效果 |
| `on_hit_effect:slow:0.3:80:2` | 造成伤害时 30% 概率附加缓慢2效果 |
| `on_hit_suppress:fire:0.1:60` | 造成伤害时 10% 概率附加火抑制 |
| `convert_dmg:<from>:<to>` | 受到<来源>伤害时转为<目标>处理（实现期定） |

### 防御 / 生存（§a）
| 代码 token（示例） | 中文显示 |
|---|---|
| `maxhp:0.3` | 最大生命值 +30% |
| `armor:4` | 护甲值 +4 |
| `kb_resist:0.2` | 击退抗性 +20% |
| `immune:fire` | 你免疫火焰伤害 |
| `immune:explosion` | 你免疫爆炸伤害 |
| `immune:poison` | 你免疫中毒效果 |
| `immune:wither` | 你免疫凋零效果 |
| `immune:projectile` | 你免疫弹射物伤害 |
| `immune:fall` | 你免疫掉落伤害 |
| `dodge:0.08` | 受击 8% 概率闪避这次伤害 |
| `dmg_taken:<set>:0.9` | 你受到套装所需的这几种生物伤害 -10% |
| `death_revive:1:12000` | 1 次不死图腾机会（冷却 10 分钟） |

### 增益 / 机动（§9）
| 代码 token（示例） | 中文显示 |
|---|---|
| `speed:0.1` | 移动速度 +10% |
| `env:water_breath` | 赋予水下呼吸效果 |
| `env:swim` | 赋予海豚恩惠效果 |
| `env:flight` | 获得创造飞行（飞行时伤害 -x%） |
| `env:dark_invis` | 赋予隐身效果 |
| `infusion_boost:1` | 全元素药水活性等级 +1 |
| `elem_activity:fire:1` | 火药水活性 +1 |
| `elem_activity:water:1` | 水药水活性 +1 |
| `elem_activity:earth:1` | 土药水活性 +1 |
| `elem_activity:ender:1` | 末影药水活性 +1 |

### 条件前缀（§e，包裹原效果）
| 代码 token（示例） | 中文显示 |
|---|---|
| `cond:night\|…` | [夜晚] … |
| `cond:day\|…` | [白天] … |
| `cond:water\|…` | [水中] … |
| `cond:fire\|…` | [火中] … |
| `cond:flying\|…` | [飞行时] … |
| `cond:armor_gt:20\|…` | [护甲值>20] … |
| `cond:hp_gt:30\|…` | [生命值>30] … |
| `cond:has_eff:<id>\|…` | [拥有<效果>] … |
| tier `when:day` / `when:night` | 状态机：按白天/夜晚切换对应档位 |

### 转化（§5）
| 代码 token（示例） | 中文显示 |
|---|---|
| `convert_eff:wither:healing` | 获得凋零时转为再生效果 |
| `convert_eff:slow:speed` | 获得缓慢时转为迅捷效果 |
| `convert_eff:<from>:<to>` | 获得<来源>时转为<目标>效果 |
| `convert_dmg:<fromTag>:<toTag>` | 受到<来源>伤害时转为<目标>处理 |

### 统一约定
- **等级一律用阿拉伯数字**：中毒2 / 虚弱1 / 缓慢2 / 迅捷3。env / infusion 等级为 1 时写「赋予隐身效果」（不带数字），带等级时写「赋予迅捷3效果」。
- `env:flight` 的 `x` 为可自定义参数；「飞行时伤害 -x%」的负号方向需实现前与使用者确认（若为飞行易伤应为 +x%）。
- `convert_eff` 的 healing 目标 = **再生效果**（`minecraft:regeneration`，持续型），非「瞬间治疗」。
- `dmg_mod:<set>` / `dmg_taken:<set>` 仅对该套装成员清单（卡组里的 3~5 个生物）生效，非生物学「同类」。

## 4. 四元素抑制（代码层 + tooltip 顶部通用块）

- 逻辑：`PhotoSetEffects.applyGenericSuppress` 实时读 `AttackerElementLoader`（即 `attacker_element` 配置），对每个元素独立统计"已装备照片中该元素活性>0 的生物"数量；≥2 张同元素 → **3%** 概率对目标附加该元素抑制，等级 = 同元素张数/2（每 +2 张等级 +1）。覆盖火/水/土/末影，无需 defs 条目。
- **概率已修正为 `0.02f` → `0.03f`（3%）**。
- **tooltip 顶部通用块**（常显，不依赖 Shift）：在 `PhotoSetRegistry.appendTooltip` 最顶部，对该照片生物读 `AttackerElementLoader.getLevel(实体, 元素)`，对**每一个活性>0 的元素**显示一行（§5）：
  > `集齐任意两张<元素>活性照片，你造成伤害后有概率触发<元素>元素抑制，每增两张该元素照片，抑制效果等级+1`
  - `<元素>` 按 火/水/土/末影 实时替换。

## 5. Tooltip 格式（锁定）

- **顶部·通用**：四元素抑制规则行（有活性才显示），§5 紫，常显。
- **套装块**：沿用现有结构——名字常显「套装：<名>」；非 Shift 时附「（Shift 查看套装效果）」；Shift 展开下方。
  - Shift 下追加表头（自动生成）：`集齐 <译名1>/<译名2>/… 照片，触发效果`
    - 译名 = `BuiltInRegistries.ENTITY_TYPE.get(id).getDescription()`，**实时读翻译键**，不写死中文。
    - 首领套特例：`集齐 3 张首领级生物照片，触发效果`。
  - 每个效果**独立一行**，按 §3 配色；条件前缀用 §e 包裹。
- 新增 `PhotoSetLoader.getMembers(setId)` 反查成员，供表头生成。

### 渲染示例（「枯骨行军」，Shift 下）
```
§5集齐任意两张火活性照片，你造成伤害后有概率触发火元素抑制，每增两张该元素照片，抑制效果等级+1
套装：枯骨行军
集齐 僵尸/小鸡/僵尸马 照片，触发效果
§e[夜晚] §a最大生命值 +30%
§c弹幕触发时发射次数 +1
```

## 6. 机制实现要点（代码位置）

- `PhotoSetEffects.buildPlan`（switch，约 `:119-142`）扩展词表：`barrage_trigger / barrage_dmg / infusion_boost / convert_eff / convert_dmg`；解析 `cond:` 前缀；tier 可带 `"when"`。
- `applyPlan`（每 tick，`:74`）逐效果按玩家**实时状态**判定条件；条件不满足→移除（属性走 `applyAttr` 反向，状态效果走 `removeEffect`）。
- 扩展 `reconcile`（`:217-230`）+ 在 persistent data 记录"本 tick 由套装授予的条件效果"，失效即清。
- `infusion_boost`：每 tick 遍历 4 种 infusion，对 active 的 amp +n。
- `convert_eff`：接 `MobEffectEvent.Applicable`（现有 `onEffectApplicable` 处 `:419-431`）改 `setResult`/替换实例；多条约实现链式 a→b→c。
- `convert_dmg`：实现期定（伤害元素转换）。
- 弹幕接入 `BossPhotoProjHelper.onSwing`（`:63`）/ `fireBossSkill`（`:80`）读 `set_flags`：
  - `barrage_trigger:n` → 每次成功判定的技能整体多触发 n 次（**不动** `:341/:224/:268/:322` 每发循环，每段仍按原 3 箭/5 牙/3 刺）。
  - `barrage_dmg:mult` → 对 `setBaseDamage`（`:348/:226`）与灵魂尖刺 `dmg`（`:273`）乘算；尖牙无伤害 setter，改走 `photo_proj` 命中乘算钩子（复用 `applySetDealtDamage` 思路）。

## 7. 50 套起草策略

- 从可拍摄生物库编组 **50 个 3~5 生物小集**，意境史诗名 + 合理效果（混用条件/弹幕/活性/转化），转化作少数彩蛋式惊喜。
- 同一生物可入多个小集。
- 草稿经使用者审阅后可微调名称/生物/效果。

### 附录样板（5 套，已确认的风格）
1. **枯骨行军**（僵尸+小鸡+僵尸马，3）：`cond:night|maxhp:0.3` + `barrage_trigger:1`
2. **熔心誓约**（ignis+blaze+lava_bat+magma_cube，4）：`immune_fire` + `cond:fire|maxhp:0.3` + `barrage_dmg:1.15`
3. **凋朽轮回**（转化彩蛋）：`convert_eff:wither:healing` + `convert_eff:slow:speed`
4. **昼夜双生**（状态机）：tier `when:day` → `dmg_mod:twin_phases:1.1`；tier `when:night` → `maxhp:0.3`
5. **首领套**（保留）：`dmg_mod:boss_barrage:1.2` + `kb_resist:0.2` + `immune_explosion` + `on_hit_effect:weak:0.1:60:0`
