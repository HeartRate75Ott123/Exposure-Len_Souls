# 照片饰品效果设计（v3 定稿）

> 本文档定义"实体照片饰品"的佩戴效果设计规格，供实现与后续调整对照。
> 现有实现骨架：`PhotographEffectRegistry`（效果注册+描述）、`PhotoSpecialEffects`（运行逻辑）、`EntityPhotographItem`（照片物品）、Curios `photograph` 槽位。

## 一、目标

对 dump 出的全部 mob（约 277 条：原版 84 / 灾变 41 / 传奇怪物 36 / 暮色 61 / 永恒星光 35 / 首领崛起 19 / lensouls 1）设计照片饰品效果：
- 符合生物特征、符合玩家直觉、强度平衡
- 核心亮点：Boss 照片概率触发原模组弹幕技能；普通 mob 给"原生物能力"（属性/药水/免疫/趣味机制）
- 适当引入负面效果（减速/减跳/减击退抗性/触及距离等）作为平衡代价

## 二、通用机制

### 2.1 Boss 弹幕触发框架

| 规则 | 设计 |
|---|---|
| 判定时机 | `PlayerTickEvent.Post` 检测攻击冷却**下降沿**：`prevScale ≥ 0.95 && curScale < 0.6`（挥击/空挥都算，节流不重复触发） |
| 概率 | 每 mob 单独配，技能越强概率越低（10%~15%） |
| 发射点 | `player.getEyePosition()`（或胸前 1 格） |
| 方向 | `player.getViewVector(1.0F)`，转 `yaw/pitch` |
| 不伤自身 | 所有弹射物统一传 `player` 作 shooter/caster；命中回调 `if (hit instanceof player)` 跳过 |
| 命中清无敌帧 | 命中回调 `target.invulnerableTime = 0` |
| 弹射物复用 | 直接 `new` 灾变/传奇怪物实体类 + `level.addFreshEntity`（compileOnly 已具备） |

### 2.2 伤害类型三分（近战/远程/魔法）

```java
魔法 = source.is(MAGIC) || source.is(INDIRECT_MAGIC) || source.is(c/neoforge:is_magic tag)
远程 = 有攻击者 && (!source.isDirect() || source.is(IS_PROJECTILE))
近战 = 有攻击者 && source.isDirect() && !source.is(IS_PROJECTILE)
```
照片的"受到的近战/远程/魔法伤害 ±%"在 `DAMAGE_RULES` 中按 kind 分发（事件结算，不注册新属性）。

### 2.3 元素增伤（数据驱动，参考 `E:\volans\Documents\GitHub\lensouls\数据参考\`）

现有元素系统：`ElementDamage = FIRE / WATER / EARTH / ENDER`，附加伤害在 `DamageHandler.onLivingDamagePre` 统一结算：
`附加伤害 = 护甲后伤害 × 受击者弱点 × Σ(攻击方活性)`。

数据源（运行时从数据包读取，/reload 热重载）：
- `attacker_element/` → `AttackerElementLoader.getElement(id)`：mob 攻击携带的元素+等级
- `entity_weakness/` → `DataPackLoader.getWeakness(id, element)`：mob 受击时各元素系数

**元素强化（佩戴者造成）**：照片 mob 有 `attacker_element`（如焰魔 `fire L4`）→ 佩戴者造成该元素**附加伤害**。实现：`DamageHandler` 元素附加伤害结算处，攻击者为玩家时，若照片 mob 的 `attacker_element` 元素 == 当前元素，`totalBonusMultiplier += 照片元素加成%`。
- 百分比 = 按 mob 活性等级换算：`level×3%`（L1→3%、L2→6%、L3→9%、L4→12%、L5→15%）。
- tooltip：`§a你造成的 火元素附加伤害 +12%`。

**元素弱点（佩戴者受到）**：照片 mob 有 `entity_weakness`（如焰魔 `water 0.5`）→ 佩戴者受到该元素**附加伤害**增加。实现：`DamageHandler` 查弱点时，受击者是玩家时，若照片 mob 的 `entity_weakness` 含当前元素，`weakness += 0.12`（叠加在玩家基础 0.2 之上）。
- 固定 +12%（与虚弱代价一致）。
- tooltip：`§c你受到的 水元素附加伤害 +12%`。

**同元素共存**：若 mob 强化与弱点为同一元素（如 posessed_paladin 攻击 earth / 弱 earth），两行都照实写，效果叠加（造成+12%、受到+12%）。

**远程伤害**：照片给"佩戴者远程伤害 +X%"用属性修饰符（`generic.attack_damage`），不依赖元素系统。

### 2.4 触及距离负面

- `player.block_interaction_range`（方块交互距离）与 `player.entity_interaction_range`（实体交互距离）**各自独立修饰**。
- 典型负面：`-0.5 ~ -1.0`（ADD_VALUE 负值）。

### 2.5 虚弱代价（统一）

- Boss 的"近战 -X% / 受到伤害 +X%"类虚弱代价统一 **12%**（0.88 / 1.12）。
- 属性型负面（减速/减跳/减击退抗性/触及距离）保持独立幅度，属"特征负面"。

### 2.6 Tooltip 规范

- 每条效果独立一行，`§a` 正面 / `§c` 负面（`Component.literal` 解析 § 码，移除现有强制 `§7`）。
- 药水效果用阿拉伯数字：`佩戴时赋予 再生1 效果`。
- 免疫类明确对象：`佩戴时免疫 黑暗 效果` / `免疫 箭矢/弹射物 伤害` / `免疫 摔落 伤害`。
- "赋予效果"与"免疫伤害"不混用：`赋予 火焰免疫 效果` = 药水 `fire_resistance`；`免疫 火焰伤害` = 伤害免疫规则。
- 概率技能前缀 `挥击时 X% 概率…`。
- 弹幕伤害写明伤害类型（魔法/火焰/幽灵/物理）与构成（固定值 + 百分比生命）。
- 元素增伤模板：`§a 你造成的 火元素附加伤害 +12%`；`§c 你受到的 冰冻伤害 +12%`。

### 4.4 照片栏位扩展组（弱属性照片 → 额外照片栏位）

佩戴以下"属性较弱"的照片时，额外获得照片饰品栏位，让玩家可多戴照片组合效果（收藏/集齐价值）。
**所有此类照片共享上限：额外照片栏位最多 +2。**

机制：每佩戴 1 张弱照片 → 额外栏位 +1，叠加至上限 +2。tooltip 统一追加：
`§a佩戴时额外获得 1 个照片饰品栏位（可叠加，上限 +2）`

| mob | 说明（效果弱，靠槽位补价值） |
|---|---|
| `minecraft:chicken` | 仅摔落免疫 + 跳跃 10% |
| `minecraft:sheep` | 仅免疫 细雪 减速 |
| `minecraft:rabbit` | 跳跃 + 幸运1（较弱） |
| `minecraft:bat` | 创造飞行但有重负面（击退抗性 -40%） |
| `minecraft:bee` | 仅移速 10% + 攻击 5% |
| `minecraft:parrot` | 跳跃 + 摔落免疫 + 幸运1（较弱） |
| `minecraft:ocelot` | 移速 + 跳跃 + 幸运1（较弱） |
| `minecraft:squid` / `glow_squid` | 水下呼吸 + 游泳 10% |
| `minecraft:cod` / `salmon` / `tropical_fish` | 观赏鱼，低配 |
| `minecraft:tadpole` / `frog` | 低配（水陆两栖） |

与 `minecraft:vindicator`（§4.1，恒定 +1 栏位、无负面）区分：本组弱照片按张数叠加至上限 +2，作为"弱效果照片"的收藏价值补充。

**实现**：`PhotoSpecialEffects` 维护弱照片 id 集合；`onPlayerTick` 统计佩戴数量 → 动态调整 Curios 照片槽位数量（默认 1，`min(1 + 弱照片数, 3)`）；vindicator 单独恒定 +1（不占弱照片上限，最终 `min(槽, 4)`）。

## 六、实现框架

1. **新类 `BossPhotoProjHelper`**：攻击冷却下降沿检测 + 按 mob 分发弹幕（各弹射物 `new` + 命中回调统一处理"不伤玩家 + 清无敌帧"）。
2. **`PhotoSpecialEffects` 扩展**：
   - `DAMAGE_RULES` 增加 kind 维度（近战/远程/魔法）与元素弱点（multiplier 0.88 / 1.12）。
   - `ATTRIBUTES` 增加 `player.block_interaction_range` / `player.entity_interaction_range`（ADD_VALUE 负值）。
   - 增加被攻击/命中附加规则表（如焰魔烙印已有雏形、铁傀儡荆棘、naga 荆棘）。
3. **`DamageHandler`**（元素增伤数据驱动，不硬编码）：
   - 元素强化（佩戴者造成）：攻击者为玩家时，遍历照片 mob，查 `AttackerElementLoader.getElement(mobId)` → 元素==当前元素 → `totalBonusMultiplier += level×3%`。
   - 元素弱点（佩戴者受到）：受击者是玩家时，遍历照片 mob，查 `DataPackLoader.getWeakness(mobId, element)` → 配置过该元素 → `weakness += 0.12`。
4. **`PhotographEffectRegistry`**：注册方式补充 `projectile`（弹幕）、`elementBonus`、`weakness`，描述支持 § 颜色多行。
5. **Curios 槽位扩展**：`minecraft:vindicator` 照片恒定 +1 照片槽位；§4.4 弱照片组按张数叠加额外照片槽位（上限 +2，vindicator 额外 +1）。实现用 Curios `ICuriosItemHandler` transient slot 动态增减，卸下恢复。
6. **Tooltip 渲染**：移除强制 `§7`，直接解析描述内 § 码；`DESCRIPTIONS` 按行渲染。
7. **原版属性修饰符池**：参考 `新建文件夹/*.json`（原版 33 + neoforge 3 + mod 自定义），只用原版/neoforge 属性（mod 自定义属性不可用，因非必装）。
