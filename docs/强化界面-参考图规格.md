## 4. 换算成实现规则（以「格子边长 k」为单位）

设 `k` = 一个网格格子的边长（参考图 k=74，实际按窗口自适应）。

| 量 | 参考图像素 | 换算 | 公式 |
|---|---|---|---|
| 单格 | 74 | 1.000 k | `k` |
| 列距 | 84 | 1.135 k | `round(84/74·k)` |
| 行距 | 91 | 1.230 k | `round(91/74·k)` |
| 大方框宽 | 158 | 2.135 k | `round(158/74·k)` |
| 大方框高 | 156 | 2.108 k | `round(156/74·k)` |
| 网格宽 | 831 | **11.216 k** | `10k + 9·gap` |
| 网格高 | 436 | **5.919 k** | `5k + 4·gap` |
| 搜索条 x 偏移（相对网格左缘） | +235 | **3.176 k** | `round(3.176·k)` |
| 搜索条 y 偏移（相对方框顶） | +106 | **1.432 k** | `round(1.432·k)` |
| 搜索条高 | 49 | 0.662 k | `round(49/74·k)` |
| 搜索条宽 | 596 | 8.040 k | 由右缘对齐反推：`网格右 − 搜索条 x` |
| 网格 y 偏移（相对方框顶） | +216 | **2.919 k** | `round(2.919·k)` |
| 开关行高 | 28 | 0.378 k | `round(28/74·k)` |
| 开关行距 | 50 | 0.676 k | `round(50/74·k)` |
| 开关方块 | 17 | 0.230 k | `round(0.23·k)` |
| 开关第 1 行顶（相对方框顶） | −24 | **−0.324 k** | 开关在方框**上方**起算 |
| 开关右内缩（相对网格右缘） | 20 | 0.270 k | 方块右缘 |
| 滚动条宽 | 24 | 0.324 k | `round(24/74·k)` |
| 滚动条左距（相对网格右缘） | 26 | 0.351 k | `round(26/74·k)` |

**内容块总尺寸（用于自适应与居中）：**

```
内容宽 = 网格宽 + 滚动条左距 + 滚动条宽 = 11.216k + 0.351k + 0.324k = 11.892 k
内容高 = (网格顶 − 开关第 1 行顶) + 网格高 = (2.919 + 0.324)k + 5.919k = 9.162 k
k = floor( min( (窗口宽 − 2·边距) / 11.892 , (窗口高 − 2·边距) / 9.162 ) )   // 边距取 6，k 夹在 14..40
```

**布局公式（先算内容块居中的 origin，再由 origin 推各模块）：**

```
originX = (窗口宽 − round(11.892k)) / 2
originY = (窗口高 − round(9.162k)) / 2

大方框   : x = originX                    y = originY + round(0.324k)      宽 = round(2.135k)  高 = round(2.108k)
搜索条   : x = originX + round(3.176k)    y = 大方框 y + round(1.432k)     高 = round(0.662k)
           宽 = (网格右缘) − 搜索条 x        // 右缘对齐
网格     : x = originX                    y = originY + round(3.243k)      宽 = round(11.216k) 高 = round(5.919k)
开关     : 第 i(0/1) 行 y = originY + round(i·0.676k)  高 = round(0.378k)
           方块右缘 = 网格右缘 − round(0.27k)；方块边长 = round(0.23k)；标签右对齐到方块左缘 − round(0.2k)
滚动条   : x = 网格右缘 + round(0.351k)   y = 网格 y                        宽 = round(0.324k)  高 = 网格高
格子(row,col): x = 网格x + col·round(1.135k)   y = 网格y + row·round(1.230k)
```

## 5. 参考图**没有**表达、需要另行约定的部分

实现时必须自行决定（参考图是空壳）：

1. **格子内容**：参考图 50 个格子全空。物品图标、右上角收藏星、右下角数量、居中「已强化」三者的位置与大小需另定（当前实现：图标按 `0.54k` 放大居中；星 9×9 贴右上 `0.06k` 内边距；数量右下角、随格宽缩放；「已强化」居中、暗色蒙版 `#000000` α≈0.7 + 绿色文字）。
2. **大方框内容**：参考图空框。当前实现为选中物品放大 `0.5·min(w,h)/16` 居中 + 右下角数量角标；空态在框内居中显示提示文字。
3. **字体**：参考图的标签是**大号粗体无衬线**（字高约 28px，而格子才 74px）。Minecraft 默认字体 1× 只有 9px 高，无法复刻该字号；要么把字体放大 2 倍绘制，要么接受 1× 字号（当前实现用 1× + 白色/灰色）。
4. **搜索框只有底/右对齐约束**：左缘由「方框右 + 1.041k」决定；参考图里搜索框内没有文字与光标。
5. **悬停/按下态**：参考图全是静态默认态，没有 hover 高亮、没有 `已强化` 标记、没有列表为空提示。
6. **滚动条语义**：参考图滑块占轨道 52.6%，只是一个示意，不代表真实条目数。

## 6. 一句话给实现者

> 把「大方框 + 搜索条 + 10×5 格子 + 右侧滚动条 + 右上两个开关」看成**一个整体内容块**，
> 以格子边长 `k` 为唯一缩放单位，内容块尺寸固定为 `11.892k × 9.162k`，在窗口里居中；
> 所有模块位置由第 4 节的公式推出，颜色只用 `#1E1E1E / #0F0F0F / #A7A7A7 / #22FF46 / #FDFEFD` 五种，
> 无边框、无圆角、无渐变——这样就能还原参考图的「疏密关系」与视觉重心。
