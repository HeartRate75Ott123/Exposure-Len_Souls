# 照片套装效果 + 饰品相册 · 设计文档

> 模组 `lensouls`（NeoForge 1.21.1）。本文件汇总照片「套装效果」与「饰品相册」的完整设计，供实现与后续维护参考。
> 所有套装**数据驱动**，Java 不写死任何一套的成员/阈值/效果。

---

## 0. 目标

1. **通用套装（按元素）**：装备 ≥2 张同元素照片时，每次你造成伤害 2% 概率给被击敌人施加对应元素抑制，等级 = 同元素张数/2（每多两张 +1），持续 ~5s。描述：`§a装备两张同元素照片时，你有2%概率施加这种元素抑制，每多两张，抑制等级+1`。
2. **特殊套装（按主题）**：≥20 套，主题归类（亡灵/龙类/水生/末影/…），有机制、有巧思、强度随获取难度递增；装备达阈值张数触发。
3. **饰品相册**：curio 容器物品，9 格（3×3，发射器 UI），右键打开存入多张合法照片；装备相册等效于其内照片全部装备（去重 + 边界安全）。
4. **数据一致性**：套装归属按 `stolen_entity` 运行时查数据推导，拍照注入照片与创造注册照片天然一致。

---

## 1. 架构总览

| 模块 | 文件 | 作用 |
|---|---|---|
| 抑制效果（前置） | `effect/ModEffects` + 新 `handler/SuppressHandler` | 4 个 `suppress_*` 效果 + 持续 tick 移除同元素活性 |
| 套装成员数据 | `config/PhotoSetLoader`（`SimpleJsonResourceReloadListener`，`data/lensouls/photo_set/*.json`） | `entityId → [setId]` 成员归属 |
| 套装定义数据 | `data/lensouls/photo_set/defs.json` | `setId → {name, desc, tiers, rule?}` |
| 套装运行时 | 新 `integration/PhotoSetRegistry` + `integration/PhotoSetEffects` | 加载数据 + 每 tick 施加 |
| 枚举入口 | `integration/PhotoSpecialEffects.collectGearEntities` | 唯一来源，展开相册内容 |
| 相册 | `item/PhotoAlbumItem` + `gui/AlbumMenu` + `gui/AlbumScreen` + `ModMenus.PHOTO_ALBUM` | 容器饰品 |

**唯一挂接点**：`collectGearEntities` 是属性/伤害/免伤/元素追伤的统一来源。相册内容在此展开 → 相册「等效装备」。现有 `!ids.contains(stolen)` 去重天然保证：多羊不重复、相册猪+外槽猪只算一次、拿走相册不误删外槽猪（轮询式每 tick 重算，无显式卸下移除）。

## 2. 数据包格式（内置进 jar）

### 2.1 成员归属 `data/lensouls/photo_set/*.json`
```json
{ "minecraft:zombie": ["undead"], "minecraft:skeleton": ["undead"], "cataclysm:draugr": ["undead"] }
```
多文件合并；一个实体可属于多套。

### 2.2 套装定义 `data/lensouls/photo_set/defs.json`
```json
{
  "undead": {
    "name": "亡灵套",
    "desc": "集齐亡灵照片：最大生命+50%，一次不死图腾机会（冷却10min）",
    "tiers": [ { "count": 3, "effects": ["maxhp:0.5", "death_revive:1:12000"] } ]
  },
  "element_fire": {
    "rule": "same_element", "element": "fire",
    "name": "炎之共鸣",
    "desc": "装备两张同元素照片时，你有2%概率施加这种元素抑制，每多两张，抑制等级+1",
    "tiers": [ { "count": 2, "effects": ["on_hit_suppress:fire:0.02:100"] } ]
  }
}
```

### 2.3 效果描述符（kind，数据引用，Java 侧实现）
- `maxhp:<倍率>` 最大生命乘算（0.5 = +50%）
- `armor:<值>` 护甲加值
- `kb_resist:<值>` 击退抗性
- `speed:<值>` 移速加值（加算，负为减）
- `elem_activity:<元素>:<值>` 该元素活性加值
- `immune:<flag>` 免疫（fire/poison/radiation/dark/magic_reflect/…）
- `on_hit_suppress:<元素>:<概率>:<时长tick>` 命中概率给敌人上该元素抑制，等级=同元素张数/2
- `on_hit_effect:<效果>:<概率>:<时长>` 命中附加（slow/poison/freeze）
- `death_revive:<次数>:<冷却tick>` 死亡图腾
- `env:<flag>` 环境增益（water_breath/flight/ lava_walk/dark_invis）
- `dmg_mod:<目标标签>:<倍率>` 对某类实体伤害±%

## 4. 相册

- **物品** `PhotoAlbumItem extends Item`，`stacksTo(1)`，用 `DataComponents.CONTAINER`(ItemContainerContents) 存照片；纹理 `assets/lensouls/textures/item/photo_album.png`（16×64 精灵图，4 帧）+ `photo_album.png.mcmeta` 动画。
- **curio**：加入 `data/curios/tags/item/photograph.json`，`CuriosIntegration.onCurioCanEquip` 对相册放行。
- **GUI**：仿 `ConverterMenu`/`ConverterScreen`：右键 `openMenu`，`dispenser.png` 贴图；`AlbumSlot.mayPlace` 仅允许 `getStolenEntity≠null && hasEffect(entityId)`（JEI 注册或能力窃取拍到的照片）；`setChanged` 写回 `CONTAINER`。
- **tooltip**：`§a右键打开容器，存入多张饰品照片`。
- **展开**：`collectGearEntities` 遇到相册 stack → 遍历其 `CONTAINER` 内照片 `add stolen_entity`。

## 5. 关键决策（已与用户确认）

- 通用抑制触发：**每次造成伤害时 2% 掷骰**给被击敌人上对应元素抑制（~5s，等级=同元素张数/2）。
- 相册容量：**9 格（3×3）**。
- `attacker_element` **不内置**（外部数据包，运行时读，缺失惰性）；`photo_set` 系列**内置**进 jar。
- 镜魂（右键激活）不进照片槽、**不纳入套装**；通用套装统一用照片口径 `attacker_element`。
- 套装全数据驱动，Java 不写死。

## 6. 实施顺序

- **Phase 0**：4 个 `suppress_*` 效果 + `SuppressHandler`（前置）。
- **Phase 1**：相册物品 + curio + GUI + `collectGearEntities` 展开。
- **Phase 2**：通用元素套装（伤害事件 2% 掷骰 + 抑制）。
- **Phase 3**：`PhotoSetLoader` + `defs` + `PhotoSetEffects` 框架 + 22 套数据 + Shift tooltip。
- **Phase 4**：构建复制桌面 + 存档验证（去重/相册/各套装）。
