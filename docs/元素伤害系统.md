# 元素伤害系统

> **口径以 `src/main/java/com/plumejade/lensouls/damage/DamageHandler.java` 为准**（2026-11 按代码重写；
> 旧版「五条检测路径 + 活性集门控」与「等级 1 = 1.2 倍」都已作废，见文末沿革）。

## 公式

- 追加以**护甲后**伤害为基数（`event.getNewDamage()`，护甲在事件前已结算）：
  `最终 = 护甲后 + 护甲后 × Σ_元素(活性Σ × 弱点)`，若有远程命中再 `+ 弱点(弹射物)`。
- 元素之间**加算**（`totalBonusMultiplier += 活性Σ × 弱点`），最后一次性乘到护甲后伤害上，`event.setNewDamage(...)`。
- 活性等级 → 倍率：`ElementDamage.getActivityByLevel(L) = 1 + (L-1) × 0.5`
  ⇒ **L1 = 1.0**、L2 = 1.5、L3 = 2.0、L5 = 3.0（`getActivityByAmplifier` 同式）。
- 弱点：`DataPackLoader.getWeakness` 读数据包显式配置；**未配置元素给 0.1 兜底**，
  所以「识别弱点」时必须只认显式配置的元素，别把 0.1 兜底当成"有这个弱点"。

## 活性来源（逐元素求和）

| 来源 | 取法 |
|---|---|
| 武器 | `ItemElementActivityLoader.getLevel(武器 id, 元素)` → `getActivityByLevel`。**弱点透镜照片**装在同一元素上时取 `max(武器等级, 2)`（`WeaknessLensPhoto.ACTIVITY_LEVEL`）|
| 攻击者实体（非玩家） | `AttackerElementLoader.getActivity(实体 id, 元素)`；其等级同时用于下面的免伤对抗 |
| 攻击者药水 | 攻击者身上该元素的 `ElementInfusionEffect` / `SoulDotEffect` → `getActivityByAmplifier(amplifier)` |
| 次元枪子弹 | 子弹元素固定 **+2.0** |
| 伤害类型 | `DamageTypeElementLoader.getActivity(damageTypeId, 元素)`，**无条件累加**（无门控、不清零）|

## 计算顺序与闸

1. 逐元素遍历；`活性Σ ≤ 0` → 跳过该元素。
2. **免伤对抗**：受击方同元素药水等级 ≥ 攻击方等级（且攻击方等级 > 0）→ 该元素追加**完全免疫**。
3. 弱点 > 0 才累加；镜魂 DoT 跳伤不喷螺旋粒子（追伤照常结算）。
4. **弹射物**：`RangedAttackHelper.isRanged(source)` 或次元枪子弹 → 额外加 `弱点(PROJECTILE)`（活性隐含 1.0）。
5. 羽·折翼沉渊佩戴者受到的**元素附加** ×1.12。
6. 一次性写回护甲后伤害；羽·元素觉醒者的反转条件（活性 ≥10 且生命 ≥90%）在此记账。

## 照片相关的两个乘区

- **照片元素追伤**：佩戴者攻击时，按照片 mob 的 `attacker_element` 等级 ×3% 逐元素追加。
  **必须在该元素已有活性时才加**——曾把加法提到闸外，结果空手也能吃加成（火照片 = 无条件 +3%/级），属行为回归。
- **照片弱点**：读玩家 `ModAttributes.*_WEAKNESS`（基值 1.0，系数 = 值 − 1），累加到该元素弱点上。

## 武器匹配 ×0.1 惩罚

目标有**非弹射物**显式弱点（>0），而玩家武器活性（含照片 2 级）与次元枪子弹元素都不匹配任一弱点
→ 最终伤害拦到 `getOriginalDamage() × 0.1`（空手、无元素武器同样吃）。

豁免面（缺一条就会误伤）：弹射物命中且目标有弹射物弱点、gytrinket 构造体（`isGytrinketDamage`）、
克拉肯船炮（`isKrakenCannonball`）、正在结算的 DoT 元素属于目标弱点。

## 弱点数据包

`data/lensouls/entity_weakness/*.json`（内容映射：物品/实体 id → 元素倍率，`/reload` 热重载）。
注意：**jar 内没有** `entity_weakness/`、`attacker_element/`，`item_element_activity/` 是空目录
——这些是留给整合包/数据包的约定，不是内置数据，排查"为什么没元素伤害"时先确认数据包在不在。

## 沿革（旧文档的错，别再照抄）

  全库没有 `activeElements`，伤害类型活性也不再因"不在活性集中"被清零。
