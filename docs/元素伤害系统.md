# 元素伤害系统

## 核心规则

**元素独立，一一配对。**

每个元素独立计算，活性与弱点**必须匹配同一元素**才生效：

```
某元素追加 = 原伤害 × 该元素总活性 × 目标对该元素弱点
总伤害 = 原伤害 + Σ(各元素追加)
```

不同元素的追加累加，互不影响。

---

## 活性来源（决定"你当前激活了哪些元素"）

| 来源 | 数据包路径 | 说明 |
|------|-----------|------|
| 武器 `item_element_activity` | `data/*/item_element_activity/*.json` | 武器自身携带的元素活性 |
| 灌注 `ElementInfusionEffect` | — | 镜魂激活后给予的药水效果 |
| DamageType 映射 | `data/*/damage_type_element/*.json` | **非独立来源**，仅当玩家已有该元素活性时作为倍率增幅 |
| AttackerEntity 映射 | `data/*/attacker_element/*.json` | 攻击者实体本身的元素映射（如烈焰人→火） |

> DamageType 和 AttackerEntity 映射对于玩家攻击而言**不是独立活性来源**，只在玩家已有该元素活性（武器/灌注）时叠加生效。

## 五条检测路径（按顺序执行）

### 活性元素集 `activeElements`

在执行①②时自动收集玩家激活的元素，路径④⑤对玩家**仅当元素在活性集中**才生效。

```
① 灌注路径
   for each active ElementInfusionEffect:
     activeElements.add(灌注元素)
     if 弱点>0 AND (药水活性>0 OR 武器活性>0):
       追加 += (武器活性 + 药水活性) × 弱点
       发射粒子（显式弱点时）
     BOSS命中粒子（如适用）

② 独立武器路径（跳过灌注已处理的元素）
   for each 武器活性元素:
     if 已在activeElements: continue（已由灌注处理）
     activeElements.add(元素)
     if 武器活性>0 AND 弱点>0:
       追加 += 武器活性 × 弱点
       发射粒子（显式弱点时）

③ 弹射物路径（无条件）
   totalBonusMultiplier += projectile弱点（默认0）
   if 弱点>0: 发射粒子
```

### 门控路径

```
④ DamageType 映射
   if hasMapping(dtId):
     dtActivity = getActivity(dtId)
     if source是玩家 AND dtElement不在activeElements: dtActivity = 0
     if dtActivity>0 AND 弱点>0:
       追加 += dtActivity × 弱点
       发射粒子（显式弱点时）

⑤ AttackerEntity 映射
   if hasMapping(attackerId):
     atkActivity = getActivity(attackerId)
     if source是玩家 AND atkElement不在activeElements: atkActivity = 0
     if atkActivity>0 AND 弱点>0:
       追加 += atkActivity × 弱点
       发射粒子（显式弱点时）
```

> 非玩家的攻击者（骷髅、烈焰人、灾变BOSS等）不受门控限制，路径④⑤无条件执行。

### 伤害应用

```
if 总追加倍率 > 0:
   bonusDamage = 原伤害 × 总追加倍率
   event.setNewDamage(原伤害 + bonusDamage)
```

## 弱点值规则

| 情况 | 返回值 |
|------|--------|
| `entity_weakness/*.json` 中显式配置 | 配置值（≥0） |
| 未配置，`PEOJECTILE` | 0 |
| 未配置，其余元素（FIRE/WATER/EARTH/ENDER） | **0.1**（基础增伤） |

- 显式配置的弱点 → 发射 UP 螺旋粒子
- 默认 0.1 → **有增伤，不发射粒子**

---

## 粒子发射

所有路径统一调用 `emitSpiralParticle(level, target, element)`，内部判断：

```
if 服务端 AND 目标有该元素的显式弱点:
   发射 UP 螺旋粒子
```

| 路径 | 触发条件 |
|------|---------|
| ① 灌注 | `weakness > 0 && (药水活性>0 OR 武器活性>0)` 时调用 |
| ② 独立武器 | `weakness > 0` 时调用 |
| ③ 弹射物 | `projWeakness > 0` 时调用 |
| ④ DamageType | 门控通过 + `weakness > 0` 时调用 |
| ⑤ AttackerEntity | 门控通过 + `weakness > 0` 时调用 |

## 计算示例

### 场景 1：下界合金剑（大地II）× 史莱姆（earth:1.5, fire:1.25）

```
无灌注，DamageType 无 player_attack 映射

activeElements = {大地}

大地追加 = 8 × 1.5(武器活性) × 1.5(大地弱点) = 18
总伤害 = 8 + 18 = 26
粒子：史莱姆有显式大地弱点 → 发射大地螺旋粒子
```

### 场景 2：下界合金剑（大地II）× 焰魔（water:0.8）

```
无灌注

activeElements = {大地}
焰魔大地弱点 = 默认 0.1（无显式配置）

大地追加 = 8 × 1.5 × 0.1 = 1.2
总伤害 = 8 + 1.2 = 9.2
粒子：焰魔无显式大地弱点 → 不发射
```

### 场景 3：下界合金剑（大地II）+ 火焰灌注（火I）× 史莱姆

```
灌注激活火I → activeElements = {大地, 火}

大地追加 = 8 × 1.5(武器) × 1.5(大地弱点) = 18
火追加   = 8 × 1.2(药水) × 1.25(火弱点) = 12
总伤害 = 8 + 18 + 12 = 38
粒子：大地+火均有显式配置 → 两种粒子
```

### 场景 4：火焰镜魂（火I）× 僵尸（fire:1.5, 无武器活性）

```
灌注激活火I → activeElements = {火}
武器无元素活性

火追加 = 8 × (0 + 1.2) × 1.5 = 14.4
总伤害 = 8 + 14.4 = 22.4
```

## 数据包文件格式

| 文件夹 | 文件 | 格式 |
|--------|------|------|
| `entity_weakness/` | 任意文件名.json | `{ "entity:id": { "元素名": 倍率 } }` |
| `item_element_activity/` | 任意文件名.json | `{ "item:id": { "values": { "元素名": 等级(1-5) } } }` |
| `damage_type_element/` | 任意文件名.json | `{ "damage_type:id": { "element": "元素名", "activity": 倍率 } }` |
| `attacker_element/` | 任意文件名.json | `{ "entity:id": { "element": "元素名", "activity": 倍率 } }` |

元素名可选值：`fire`、`water`、`earth`、`ender`、`projectile`

`entity_weakness` 的倍率公式：`追加 = 原伤害 × 活性 × 倍率`。
`item_element_activity` 的等级映射：1→1.2x、2→1.5x、3→2.0x、4→2.5x、5→3.0x。
