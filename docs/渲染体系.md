# LenSouls 渲染技术体系

> 通过对 AdorableArmory、AlexCaves、ItemGlint、ShaderTest、EpicFight、ArsNouveau、
> TwilightForest、gytrinket、fancy-vfx、Ambiance 共 10 个模组源码的系统学习，
> 结合 lensouls 自身渲染开发经验（3 条独立渲染管线）沉淀形成。

---

## 一、Minecraft 渲染管线总览

```
顶点数据 → Vertex Shader (vsh) → 光栅化 → Fragment Shader (fsh) → 深度测试 → 输出
  ↑                                                                        ↓
  Core Shader JSON (顶点格式+uniform声明)                                  ↓
  ↑                                                                        ↓
  RenderType (状态组合: 剔除/混合/深度/写入)                              ↓
  ↑                                                                        ↓
  MultiBufferSource.getBuffer(RenderType) → BufferUploader                 ↓
  ↑                                                                        ↓
  RenderLevelStageEvent (按阶段排序)                                       ↓
  ↑                                                                        ↓
  LevelRenderer → GameRenderer                                              ↓
  ↑                                                                        ↓
  Post Chain (后处理json) ← 最终帧缓冲 ←──────────────────────────────────────
```

### 两大着色器类型

| 类型 | 作用 | 输入 | 输出 |
|------|------|------|------|
| **Core Shader（核心）** | 渲染具体游戏内容（方块/实体/粒子） | 顶点属性(Position/Color/UV/Normal) + uniform | 片元颜色(写入帧缓冲) |
| **Post Chain（后处理）** | 全屏后处理（辉光/模糊/色调） | 帧缓冲纹理(sampler) + uniform | 最终屏幕颜色 |

## 二、Core Shader 系统

### 2.1 注册流程

```
RegisterShadersEvent
  → new ShaderInstance(provider, location, vertexFormat)
    → 自动加载 location.vsh + location.fsh + location.json
  → event.registerShader(instance, callback)
    → callback 中保存到 ShaderRegistry 静态字段
```

**典型注册代码**（参考 lenSouls + ArsNouveau）：
```java
@SubscribeEvent
static void registerShaders(RegisterShadersEvent event) {
    ResourceProvider provider = event.getResourceProvider();
    ShaderInstance shader = new ShaderInstance(provider,
        ResourceLocation.fromNamespaceAndPath(MODID, "rendertype_entity_outline"),
        DefaultVertexFormat.NEW_ENTITY);
    event.registerShader(shader, instance -> MyRegistry.shader = instance);
}
```

### 2.2 JSON 定义结构

```json
{
    "vertex": "rendertype_entity_translucent",  // 复用原版 vsh
    "fragment": "lensouls:rendertype_entity_outline",  // 自定义 fsh
    "samplers": [
        { "name": "Sampler0" }  // 纹理采样器，无纹理可省略
    ],
    "attributes": ["Position", "Color", "UV0", "UV1", "UV2", "Normal"],
    "uniforms": [
        { "name": "ModelViewMat", "type": "matrix4x4", "count": 16, "values": [...] },
        { "name": "ProjMat",      "type": "matrix4x4", "count": 16, "values": [...] },
        { "name": "ColorModulator","type": "float",    "count": 4,  "values": [1,1,1,1] },
        { "name": "GameTime",     "type": "float",     "count": 1,  "values": [0.0] }
    ]
}
```

**关键要点**：
- `vertex` 可以复用原版（如 `rendertype_entity_translucent`），`fragment` 必须是自己
- `attributes` 必须与 `DefaultVertexFormat` 匹配
- 自定义 uniform 在 json 中声明默认值，运行时用 `shader.getUniform("Name").set(value)` 更新

### 2.3 已知可用的 Core Shader uniform

| uniform | 类型 | 说明 | 可用 |
|---------|------|------|------|
| `ModelViewMat` | mat4 | 模型视图矩阵 | 全部 |
| `ProjMat` | mat4 | 投影矩阵 | 全部 |
| `ColorModulator` | vec4 | 颜色乘法器，由游戏代码设置 | 核心 |
| `GameTime` | float | 世界时间（游戏日），需手动更新 | 核心 |
| `ScreenSize` | vec2 | 帧缓冲大小 | 核心 |
| `FogStart` / `FogEnd` | float | 雾距 | 核心 |
| `FogColor` | vec4 | 雾颜色 | 核心 |
| `Light0_Direction` / `Light1_Direction` | vec3 | 光照方向 | 实体相关 |
| `ChunkOffset` | vec3 | 区块偏移 | 方块相关 |
| `LineWidth` | float | 线宽 | lines 着色器 |

### 2.4 VertexFormat 选择指南

| Format | 顶点属性 | 适用场景 |
|--------|---------|---------|
| `NEW_ENTITY` | Position+Color+UV0+UV1+UV2+Normal | 实体渲染(复用 entity 管线) |
| `POSITION_COLOR` | Position+Color | 自定义几何(球体/环/光柱) |
| `POSITION_COLOR_NORMAL` | Position+Color+Normal | 线框/法线相关 |
| `POSITION_TEX` | Position+UV | 全屏后处理quad |
| `BLOCK` | Position+Color+UV0+UV1+Normal | 方块渲染 |

### 2.5 Fragment Shader 编写规范

**标准入口模板**（#version 150）：
```glsl
#version 150
uniform vec4 ColorModulator;
uniform float GameTime;
in vec4 vertexColor;
in vec2 texCoord0;
out vec4 fragColor;

void main() {
    float alpha = vertexColor.a;
    if (alpha < 0.01) discard;
    fragColor = vec4(finalColor, alpha) * ColorModulator;
}
```

**核心技巧**：
- `discard` 丢弃片元（不写入深度/颜色），用于透明裁剪
- `vertexColor.a` 是模型层面控制的透明度（如 `colorARGB` 的 alpha）
- `* ColorModulator` 结尾，让游戏内部可以调控全局颜色
- `texCoord0` 是 UV 坐标（0~1），用于纹理采样或位置计算

### 2.6 进阶 GLSL 技术

#### 哈希/噪声函数（参考 ShaderTest sky_ring.fsh + ArsNouveau blamed_entity.vsh）

```glsl
// 简易2D哈希
float hash(vec2 p) {
    return fract(sin(dot(p, vec2(127.1, 311.7))) * 43758.5453123);
}

// 值噪声（插值版）
float noise(vec2 p) {
    vec2 i = floor(p);
    vec2 f = fract(p);
    float a = hash(i);
    float b = hash(i + vec2(1.0, 0.0));
    float c = hash(i + vec2(0.0, 1.0));
    float d = hash(i + vec2(1.0, 1.0));
    vec2 u = f * f * (3.0 - 2.0 * f);
    return mix(a, b, u.x) + (c - a) * u.y * (1.0 - u.x) + (d - b) * u.x * u.y;
}

// FBM 分形噪声
float fbm(vec2 p) {
    float value = 0.0;
    float amplitude = 0.5;
    for (int i = 0; i < 4; ++i) {
        value += noise(p) * amplitude;
        p = p * 2.0 + vec2(17.2, 11.8);
        amplitude *= 0.5;
    }
    return value;
}

// 辅助函数
float saturate(float x) { return clamp(x, 0.0, 1.0); }
float gaussianRing(float x, float center, float width) {
    return exp(-pow((x - center) / max(width, 0.0001), 2.0));
}
```

**用途**：有机纹理扰动、粒子闪烁、黄金流纹、极光波动、顶点偏移噪声

#### 顶点偏移（参考 ArsNouveau blamed_entity.vsh）

在 vertex shader 中用噪声偏移顶点位置，实现"颤抖/扭曲"效果：

```glsl
// 关键行
float displacement = snoise(Position + GameTime * 800.0) * 0.1;
vec3 offsetPos = Position + normal * displacement;
gl_Position = ProjMat * ModelViewMat * vec4(offsetPos, 1.0);
```

#### 射线步进（参考 Twilight Forest aurora.fsh）

```glsl
for (int i = 0; i < 16; i++) {
    vec3 samplePos = ro + rd * dist;
    float noiseVal = noise(samplePos.xz + GameTime * 0.02);
    density += noiseVal * (1.0 - dist / maxDist);
    dist += stepSize;
}
```

## 三、RenderType 体系

### 3.1 创建自定义 RenderType

核心 API：`RenderType.create(name, format, mode, bufferSize, affectsCrumbling, sortOnUpload, state)`。

**标准模式**（参考 WireframeRenderTypes + EntityOutlineRenderType）：
```java
public class MyRenderTypes {
    private static final RenderStateShard.ShaderStateShard MY_SHADER =
        new RenderStateShard.ShaderStateShard(() -> MyShaderRegistry.shader);

    private static RenderType cached;
    public static RenderType get() {
        RenderType rt = cached;
        if (rt == null) {
            rt = RenderType.create(
                "my_render_type",
                DefaultVertexFormat.NEW_ENTITY,
                VertexFormat.Mode.QUADS,
                256, true, true,
                RenderType.CompositeState.builder()
                    .setShaderState(MY_SHADER)
                    .setTransparencyState(RenderStateShard.TRANSLUCENT_TRANSPARENCY)
                    .setWriteMaskState(RenderStateShard.COLOR_WRITE)
                    .setCullState(RenderStateShard.CULL)
                    .setDepthTestState(RenderStateShard.LEQUAL_DEPTH_TEST)
                    .setOverlayState(RenderStateShard.NO_OVERLAY)
                    .setLightmapState(RenderStateShard.NO_LIGHTMAP)
                    .createCompositeState(true))   // true = outline(不排序不影响), false = translucent排序
            );
            cached = rt;
        }
        return rt;
    }
}
```

### 3.2 RenderStateShard 组件详解

| StateShard | 选项 | 说明 |
|------------|------|------|
| `ShaderStateShard` | 自定义/标准 | 绑定着色器，核心组件 |
| `TransparencyStateShard` | `TRANSLUCENT`(SRC_ALPHA, ONE_MINUS_SRC_ALPHA) / `ADDITIVE`(SRC_ALPHA, ONE) / `LIGHTNING`(SRC_ALPHA, ONE) / `GLINT`(SRC_COLOR, ONE) | 混合模式 |
| `CullStateShard` | `CULL`(背面剔除) / `NO_CULL`(双面渲染) | 注意：Cull face 方向由 GL11.glCullFace() 控制，这个 shard 只控制是否启用剔除 |
| `DepthTestStateShard` | `LEQUAL`(默认) / `EQUAL`(模板二遍) / `NO_DEPTH_TEST`(始终通过) | 深度测试策略 |
| `WriteMaskStateShard` | `COLOR_WRITE` / `COLOR_DEPTH_WRITE` / `DEPTH_WRITE` | 控制写入哪些缓冲 |
| `LightmapStateShard` | `LIGHTMAP`(启用光照) / `NO_LIGHTMAP`(无光照) | 实体光照 |
| `OverlayStateShard` | `OVERLAY`(启用覆盖) / `NO_OVERLAY`(无覆盖) | 受伤闪烁 overlay |
| `TextureStateShard` | 单纹理 / `MultiTextureStateShard` | 纹理绑定 |
| `OutputStateShard` | `MAIN_TARGET`(主缓冲) / `ITEM_ENTITY_TARGET`(后处理) | 渲染目标 |
| `LayeringStateShard` | `VIEW_OFFSET_Z_LAYERING`(防深度冲突) | 深度偏移 |

### 3.3 绕过 protected 限制（反射）

```java
// LineStateShard 构造器 protected
Constructor<RenderStateShard.LineStateShard> ctor =
    RenderStateShard.LineStateShard.class.getDeclaredConstructor(OptionalDouble.class);

```

### 3.4 多纹理 RenderType（参考 ArsNouveau FixedMultiTextureStateShard）

关键问题：原版 `MultiTextureStateShard` 用 `i++` 分配纹理 ID，会与硬编码的 Sampler1(lightmap) 和 Sampler2(overlay) 冲突。

**解决方案**：自定义 `EmptyTextureStateShard`，跳过 ID 1 和 2：
```java
public class FixedMultiTextureStateShard extends RenderStateShard.EmptyTextureStateShard {
    public FixedMultiTextureStateShard(List<Texture> textures) {
        super(() -> {
            for (int i = 0; i < textures.size(); i++) {
                int id = i >= 2 ? i + 1 : i;  // 跳过 ID 1,2
                RenderSystem.setShaderTexture(id, textures.get(i).location());
            }
        }, () -> { /* clear textures */ });
    }
}
```

### 3.5 NeoForge RenderPipeline API（参考 Twilight Forest）

NeoForge 提供了更高层的 `RenderPipeline` 抽象，替代手动 `RenderType.create()`：

```java
public static final RenderPipeline RED_THREAD = RenderPipeline.builder()
    .withShaderLocation(location)
    .withVertexFormat(DefaultVertexFormat.BLOCK, VertexFormat.Mode.QUADS)
    .withStateShards(
        RenderStateShard.CULL,
        RenderStateShard.NO_DEPTH_TEST  // ALWAYS_PASS
    )
    .build(location);
```

通过 `TFRenderTypes` 中 `new RenderPipelineRenderType(name, pipeline, ...)` 使用。

## 四、三类渲染入口

### 4.1 实体渲染层（RenderLayer）

**适用**：在已有实体上叠加效果（盔甲、手持物、附魔光效）

```java
// 注册到所有 LivingEntityRenderer
@SubscribeEvent
static void addLayers(EntityRenderersEvent.AddLayers event) {
    for (var renderer : event.getSkins()) {
        renderer.addLayer(new MyLayer(renderer));
    }
}
```

**限制**：只能渲染当前实体的主模型，不自动包含子模型（盔甲层需额外添加）

### 4.2 Mixin 后处理（Post-render 注入）

**适用**：需覆盖全部部件（身体+盔甲+手持物），或劫持渲染管线

**AdorableArmory 模式**（`@Inject RETURN` + Buffer 全替换）：
```java
@Inject(method = "render", at = @At("RETURN"))
void postRender(..., MultiBufferSource source, ...) {
    if (recursion.get()) return;
    recursion.set(true);
    try {
        // 1. 设置特殊 OpenGL 状态
        GL11.glCullFace(GL11.GL_FRONT);
        // 2. 膨胀 poseStack
        poseStack.scale(1.03f);
        // 3. Buffer 全替换 → 所有子渲染都用同一个 outline RenderType
        MultiBufferSource wrapped = rt -> source.getBuffer(outlineType);
        // 4. 重新 render 整个实体
        ((LivingEntityRenderer) this).render(entity, ..., wrapped, ...);
        // 5. flush 批次（在状态恢复前）
        ((BufferSource) source).endBatch(outlineType);
    } finally {
        GL11.glCullFace(GL11.GL_BACK);
    }
}
```

**ItemGlint 模式**（`@Inject BEFORE/AFTER` + FBO 遮罩捕获）：
```java
@Inject(method = "renderModelLists", at = @At("BEFORE"))
void captureBegin(...) {
    // 切换到遮罩 FBO → 清晰 → 只渲染物品遮罩
}
@Inject(method = "renderModelLists", at = @At("AFTER"))
void captureEnd(...) {
    // 恢复主 FBO → 标记需要合成
}
```

### 4.3 世界空间渲染（RenderLevelStageEvent）

**适用**：自定义 3D 几何（光环、尾迹、球体、光柱），与场景有正确深度关系

**三阶段策略**（参考 ShaderTest BlackHoleWorldRenderer）：

| Stage | 用途 | 示例 |
|-------|------|------|
| `AFTER_SKY` | 天空背景效果 | 黑洞引力透镜(depth capture) |
| `AFTER_WEATHER` | 自定义世界效果 | 黑洞渲染、光环、能量波 |
| `AFTER_LEVEL` | 后处理级效果 | 爆炸后期、屏幕扭曲 |
| `AFTER_ENTITIES` | 与实体同层 | 空间扭曲球体描边 |
| `AFTER_PARTICLES` | 尾迹、闪电 | gytrinket 弹道尾迹 |

**标准渲染模板**：
```java
@SubscribeEvent
static void onRenderLevel(RenderLevelStageEvent event) {
    if (event.getStage() != RenderLevelStageEvent.Stage.AFTER_WEATHER) return;
    if (shader == null) return;

    PoseStack modelView = RenderSystem.getModelViewStack();
    modelView.pushPose();
    modelView.setIdentity();
    modelView.mulPoseMatrix(event.getPoseStack().last().pose());
    RenderSystem.applyModelViewMatrix();

    RenderSystem.enableBlend();
    RenderSystem.defaultBlendFunc();
    RenderSystem.disableCull();
    RenderSystem.depthMask(false);

    for (EffectEntity entity : entities) {
        renderEffect(entity, cameraPos, partialTick);
    }

    RenderSystem.depthMask(true);
    RenderSystem.enableCull();
    RenderSystem.disableBlend();
    modelView.popPose();
    RenderSystem.applyModelViewMatrix();
}
```

**自定义 uniform 更新**（关键技巧）：
```java
// 每帧在渲染前设置自定义 uniform
shader.getUniform("OuterRadius").set(value);
shader.getUniform("InnerRadius").set(value);
shader.getUniform("Time").set(gameTime * 0.04f);
shader.getUniform("CameraPos").set(x, y, z);
```

**自定义几何构建**（BufferBuilder）：
```java
BufferBuilder buffer = Tesselator.getInstance().getBuilder();
buffer.begin(VertexFormat.Mode.TRIANGLES, DefaultVertexFormat.POSITION_COLOR);
for (/* 生成顶点 */) {
    buffer.vertex(x, y, z).color(r, g, b, a).endVertex();
}
RenderSystem.setShader(() -> shader);
BufferUploader.drawWithShader(buffer.end());
```

## 五、实体描边技术全景

这是 lensouls 积累最丰富的领域，共有 **5 种独立方案**：

| 方案 | 原理 | 模型覆盖 | 动画 | Iris兼容 | 性能 | 实现难度 |
|------|------|---------|------|---------|------|---------|
| **A: RenderLayer膨胀+背面** | 层内 GL_FRONT + scale 1.03x，只画主模型 | ❌ 无盔甲手持物 | 弱 | ⭐⭐⭐ | ⭐⭐⭐ | ⭐ |
| **B: Mixin+Buffer全替换** ← 现行 | @Inject RETURN 重绘全部，Buffer 替换所有子RenderType | ✅ 全 | ✅ 好 | ⭐⭐⭐ | ⭐⭐ | ⭐⭐⭐ |
| **C: Stencil 二遍** | 一遍 depth-only → stencil=EQUAL → 二遍放大 | ✅ 全 | ✅ 好 | ⚠ 冲突 | ⭐⭐ | ⭐⭐⭐⭐ |
| **D: FBO后处理边缘检测** | 渲染到离屏FBO → 边缘检测合成（ItemGlint） | ✅ 全 | ✅ 好 | ✅ 绿 | ⭐ | ⭐⭐⭐⭐⭐ |
| **E: 2D HUD投影框** | 投影 AABB 到屏幕 → 绘制2D角标（SkyMode） | – | ✅ 好 | ✅ 绿 | ⭐⭐⭐⭐⭐ | ⭐⭐ |

**推荐路线**：当前用 B（Mixin 后处理），如果需要更华丽的效果再升级到 D（FBO 后处理）。

### D 方案详解：FBO 后处理描边（ItemGlint 模式）

```
Pass 1: 渲染实体到离屏 FBO（纯白色遮罩）
Pass 2: glBlitFramebuffer 拷贝主场景深度到另一个 FBO
Pass 3: 全屏quad + 边缘检测着色器 → 合成到主缓冲
         (Sobel 算子检测遮罩边缘 → 获取轮廓位置)
Pass 4: 在轮廓位置渲染金色渐变
```

**关键代码**：
```java
// 创建离屏 FBO
TextureTarget maskTarget = new TextureTarget(width, height, true, true);
// 渲染前切换
maskTarget.bindWrite(true);
RenderSystem.clear(256, true);  // 清空
// 实体遮罩渲染...
// 切换回主缓冲
mainTarget.bindWrite(false);
// 全屏合成
shader.setSampler("MaskSampler", maskTarget.getColorTextureId());
```

### 6.2 自定义 ParticleRenderType（Ars Nouveau 方式）

```java
public static final ParticleRenderType EMBER_RENDER = new ParticleRenderType() {
    @Override
    public void begin(BufferBuilder bufferBuilder, TextureManager textureManager) {
        RenderSystem.depthMask(true);
        RenderSystem.enableBlend();
        RenderSystem.blendFunc(GlStateManager.SourceFactor.SRC_ALPHA,
            GlStateManager.DestFactor.ONE);  // 加法混合
        RenderSystem.setShaderTexture(0, VanillaSpriteLocations.PARTICLE_ATLAS);
        // 启用光照纹理
        Minecraft.getInstance().gameRenderer.getLightTexture().turnOnLightLayer();
    }
    @Override
    public void end(Tesselator tesselator) {
        tesselator.end();
        RenderSystem.depthMask(true);
        RenderSystem.disableBlend();
        Minecraft.getInstance().gameRenderer.getLightTexture().turnOffLightLayer();
    }
};
```

### 7.2 手动 FBO 操作（替代 PostChain，更灵活）

```java
// 创建
TextureTarget fbo = new TextureTarget(width, height, useDepth, isMac);

// 切换输入
fbo.bindWrite(false);
// 在此渲染... 

// 读取作为纹理
shader.setSampler("DiffuseSampler", fbo.getColorTextureId());

// 全屏 quad 渲染
BufferBuilder buffer = Tesselator.getInstance().getBuilder();
buffer.begin(QUADS, POSITION_TEX);
buffer.vertex(-1, -1, 0).uv(0, 0).endVertex();
buffer.vertex( 1, -1, 0).uv(1, 0).endVertex();
buffer.vertex( 1,  1, 0).uv(1, 1).endVertex();
buffer.vertex(-1,  1, 0).uv(0, 1).endVertex();
RenderSystem.setShader(() -> shader);
BufferUploader.drawWithShader(buffer.end());

// FBO 间拷贝
GlStateManager._glBindFramebuffer(36008, source.fboId);
GlStateManager._glBindFramebuffer(36009, target.fboId);
GlStateManager._glBlitFrameBuffer(0, 0, w, h, 0, 0, tw, th, mask, filter);
```

## 八、Iris/Oculus 兼容核心原则

> **通过 RenderType 管线渲染，不要直接调用 RenderSystem 裸 GL。**

### ✅ 兼容做法

1. 使用 `RenderType.create()` → `BufferSource.getBuffer(rt)` → `VertexConsumer` → `endBatch(rt)`
2. `OutputStateShard.MAIN_TARGET`（不经过后处理 FBO）
3. `@Inject`（而不是 `@Redirect`），避免与 Iris 的指令注入冲突

### ❌ 不兼容做法

1. `Tesselator` + `RenderSystem.setShader()` 裸画（Iris 不知情，着色器互相覆盖）
2. `@Redirect` 修改返回值的 mixin（与 Iris 同类注入冲突）
3. 直接读/写 GL 状态（Iris 可能在中间切换）

## 九、性能优化技术

### 9.1 VertexBuffer 缓存（参考 ArsNouveau PlanariumRenderer）

将不常变化的几何体烘焙到 `VertexBuffer`，避免每帧重建：
```java
// 构建阶段
VertexBuffer buffer = new VertexBuffer(VertexFormat.Mode.QUADS);
try {
    BufferBuilder builder = Tesselator.getInstance().begin(QUADS, format);
    // ... 添加顶点
    buffer.bind();
    buffer.upload(builder.end());
    VertexBuffer.unbind();
} catch (Exception e) { ... }

// 渲染阶段（每帧）
buffer.bind();
DefaultVertexFormat.BLOCK.setupBufferState();
BufferUploader.reset();
buffer.draw();
VertexBuffer.unbind();
```

### 9.2 惰性初始化 + 双重检查锁

```java
private static volatile RenderType cached;
public static RenderType get() {
    RenderType rt = cached;
    if (rt == null) {
        synchronized (MyClass.class) {
            rt = cached;
            if (rt == null) {
                rt = create();
                cached = rt;
            }
        }
    }
    return rt;
}
```

### 9.3 半透明排序优化

每 N 帧才重新排序一次（ArsNouveau PlanariumRenderer，21 帧间隔），防止每帧排序的性能开销。

### 9.4 可见性裁剪

```java
// Frustum 可见性测试
if (!event.getFrustum().isVisible(entity.getBoundingBox().inflate(radius))) continue;
// 距离裁剪
if (cameraPos.distanceToSqr(entity.position()) > MAX_DIST_SQ) continue;
```
